# Why progressive overload matters

Progressive overload is the principle that muscles adapt only when you gradually ask
them to do more over time. If every workout is identical — same weight, same reps —
your body has no reason to change, and progress stalls. The fix is to make training
slightly harder week over week.

You can add load in several ways: add reps to a set, add a set to the exercise, add
weight, slow the lowering phase, or shorten rest between sets. For a beginner using
bodyweight in a hostel, the easiest path is reps then sets: if you did 3 sets of 10
push-ups last week, aim for 3 sets of 11–12 this week, and add a fourth set when that
feels manageable. Once bodyweight gets easy, progress to harder variations (decline
push-ups, archer push-ups, pistol-squat progressions).

Overload should be gradual, not reckless — jumping too fast invites injury and poor
form. A common structure is to build for three weeks and take a lighter "deload" week
to recover. Track your sets and reps so you actually know whether you are progressing;
memory is unreliable, and what gets measured gets improved.
